## 建議新增規則

- 品牌懶人包：`guides/brands/<brand>_buying_guide.html`
- 現有舊檔名（例如 `gootoe.html`、`farmina-buying-guide.html`）保留原路徑，避免已公開連結失效
- 教學頁：`guides/tutorials/<topic>.html`
- 說明頁：`guides/docs/<topic>.html`

## 新增頁面時記得同步

1. 建立對應的 `.html` 檔案
2. 補上這份 `guides/README.md`
3. 如果需要入口，再從 `index.html` 或其他頁面加上連結
